# Run Deck 0.2.0

Run Deck now shows the services actually running on your Mac, including listeners started outside Muxy. Inspect their process trees and resource use, open their pages, and safely stop or restart tracked launches.

## Added

- A service dashboard with grouped listeners and child processes, CPU/RSS estimates, sorting, search, and a separate app/system section.
- Foreground-only live checks, bounded observation history, and hints for sustained CPU use, substantial memory growth, and repeated listener replacement.
- Exact terminal navigation and guarded restart for Run Deck launches. Stop checks host, process identities, descendant membership, and ports before requesting a normal exit.
- A project command picker that discovers root package scripts, selects the package manager, and reuses saved terminal associations. Custom and interactive commands remain supported.
- Remembered custom browser addresses, English/Simplified Chinese, and light/dark themes.

## Reliability and performance

- Cancelled discovery and hidden panels stop subsequent inspection work. Stale confirmations and failed scans cannot authorize actions against an obsolete observation.
- Delayed storage and terminal responses preserve concurrent edits, deletion, and replacement associations. Parallel custom-address saves retain both results.
- Parent-managed worker shutdown no longer falsely cancels restart when an exited worker briefly remains as a zombie. Live process identity changes still abort the stop.
- Interactive launch input is preserved with both macOS sh and dash-based shells.
- Different listening addresses on the same port keep separate URLs and histories. Sustained resource hints tolerate scan duration added to the five-second interval; incomplete CPU samples hide the trend chart.
- Keyed cards and lazily allocated detail rows avoid rebuilding the full process view. Search and unchanged refreshes allocate no new elements in the 200-service / 6,000-process regression fixture; history remains bounded.

## Install and upgrade

Download `run-deck-0.2.0.zip` and `SHA256SUMS` from this release. Run `shasum -a 256 -c SHA256SUMS`, extract the ZIP, then select its `run-deck/` folder in **Muxy → Extensions → Load Unpacked**. The package is unsigned and does not need Node at runtime. For an existing local installation, load the new folder or replace its files and reload the extension; keep the extension's saved data and review Muxy's permission prompts.

Native service inspection requires a macOS execution host. The extension requests process inspection/control, browser, terminal, project/worktree, storage, and file-read permissions for the documented actions. Allowing and remembering the read-only scan avoids repeated scan prompts; stopping and starting processes still require the relevant host consent.

## Limits

TCP listening is not a health check; RSS can double-count shared pages. Process verification and signalling are not atomic, and detached workers may escape a snapshot. Cross-window storage transactions are not available through the host. This release does not claim a fix for the observed WebKit memory peak. See [Validation](../VALIDATION.md) and [Architecture](../ARCHITECTURE.md) for evidence and limits.
